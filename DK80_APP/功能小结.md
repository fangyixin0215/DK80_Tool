# DK80 BLE 调试通道 — 功能小结

> 本次工作完成于 2026-10-17，为 DK80（FR2018A-U）净化器新增 BLE 调试能力，
> 解决 UART0 日志口之后要接 O3/NH3 传感器导致调试口被占用的问题。

---

## 一、需求背景

UART0 目前是日志输出口，后续将接 O3 / NH3 传感器，日志口被占用后无法再用串口调试。
方案：将关键日志和运行状态通过 BLE（GATT）推送到手机 App，同时用 App 实现板载按键遥控、设备信息查看、日志导出、OTA 升级。

---

## 二、固件侧功能

### 2.1 GATT 服务结构

服务 UUID `0xFFD0`（16 位 → 蓝牙标准 128 位基址 `0000FFD0-0000-1000-8000-00805F9B34FB`）：

| 特征 | UUID | 性质 | 用途 |
|------|------|------|------|
| CHAR1 | 0xFFD1 | Read / Notify | 16 字节二进制状态快照（传感器+风扇+UV+臭氧） |
| CHAR2 | 0xFFD2 | Write | 文本命令通道（`\n` 结尾） |
| CHAR3 | 0xFFD3 | Notify | 调试响应 + 日志流（变长文本行） |

### 2.2 文本协议

| 命令 | 方向 | 说明 |
|------|------|------|
| `HS:REQ` | App→设备 | 握手请求 |
| `HS:ACK FW=.. HW=.. BUILD=.. SN=<MAC> GAS=..` | 设备→App | 握手应答（CHAR3） |
| `KEY:<0-15>` | App→设备 | 模拟按键，复用红外码值表 |
| `INFO?` | App→设备 | 查询设备身份信息 |
| `IMEI=/ICCID=/IMSI=/MAC=/FW=/HW=/BUILD=/GAS=` + `INFO:END` | 设备→App | 信息逐行返回（CHAR3） |
| `LOG:<0|1>` | App→设备 | 开关日志流 |
| `STA?` | App→设备 | 立即推送一次 CHAR1 状态 |
| `OTA:START` | App→设备 | 进入 OTA（切到 ble_ota 服务） |

### 2.3 日志挂钩

- `dk80_ble_log.c` 挂钩 `fputc_imp`，在不影响 UART0 输出的前提下，把 `co_log` 字符流复制一份到 2KB 环形缓冲。
- 主循环 `dk80_gatt_task()` 中，当 App 使能日志流且 CHAR3 CCC 开启时，按行（到 `\n`）Notify 出去。

### 2.4 设备身份信息

- `dk80_module_net.c` 在联网建立（`ec800k_config`）时通过 `AT+GSN` / `AT+QCCID` / `AT+CIMI` 读取并缓存 IMEI / ICCID / IMSI。
- MAC 地址通过 `gap_address_get()` 实时获取。
- FW / HW 版本宏定义在 `dk80_board.h`，编译时间用 `__DATE__ __TIME__`。

### 2.5 OTA

- 调用 SDK `ota_gatt_add_service()` 注册 `ble_ota` 服务（UUID `02F00000-0000-0000-0000-00000000FE00`）。
- App 收到 `OTA:READY` 后切到该服务，通过 RX 特征写入固件。

### 2.6 量产宏控制

| 宏 | 作用 | 默认值 |
|----|------|--------|
| `DK80_BLE_DEBUG_EN` | DK80 GATT 调试服务总开关 | 1 |
| `DK80_BLE_LOG_EN` | co_log 复制到 BLE 环形缓冲 | 1 |
| OTA | 由 `ota_gatt_add_service()` 调用决定 | 开启 |

量产版可关闭日志挂钩、仅保留遥控+状态上报，或全部关闭。

## 三、Android App 功能

技术栈：Kotlin + Jetpack Compose + Material3，minSdk 26 / targetSdk 34。

### 3.1 遥控页

- 圆形按键网格，键值与固件红外码一一对应：电源(0x06)、童锁(0x05)、风+(0x0D)、风-(0x0F)、定时(0x0A)、循环(0x0E)、预约(0x0C)、时+(0x00)、时-(0x04)、分+(0x01)、分-(0x03)、时间/确认(0x02)、复位/取消(0x0B)。
- 直接调用 `dk80_mode_ir_cmd`，与板载按键/红外遥控器行为完全一致。

### 3.2 工况页

- 实时工况卡：PM2.5 / PM10 / NH₃或O₃ / 温度 / 湿度 / 风速档 / UV / 臭氧发生器。
- 设备身份卡：IMEI / ICCID / IMSI / MAC / 固件版本 / 硬件版本 / 编译时间 / 气体类型。
- 支持手动刷新信息和状态。

### 3.3 日志页

- 实时日志流（`LOG:1` 开启），深色终端风格，等宽字体。
- 支持清空、一键导出为 txt 并通过系统分享（微信/邮件/保存到文件）。
- 日志保留最近 2000 行，自动滚动到底部。

### 3.4 OTA 页

- 选择固件 bin 文件 → `OTA:START` → 按 MTU-3 分片写入 ble_ota RX 特征。
- 带进度条显示。

### 3.5 BLE 通信层（BleManager）

- 扫描：按 DK80 服务 UUID 过滤，10 秒超时。
- 连接流程：`connectGatt` → `requestMtu(247)` → `discoverServices` → 开 CHAR1/CHAR3 通知 → 发 `HS:REQ` → 收到 `HS:ACK` 进入 Ready。
- 串行写队列：保证 GATT write 有序，超过 MTU-3 自动分片。
- 状态通过 `StateFlow` 暴露给 UI。
